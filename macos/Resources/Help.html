Make room for the ocean.

A live ocean for your desktop, screen saver and lock screen.

GitHub beta. This download is not Apple-notarized. macOS may block it the first time. Only install a copy you trust from Ocean’s GitHub releases. Follow Apple’s instructions if you choose to approve it. You do not need to disable system security or run Terminal commands.

Install and start

  1. Download the Ocean disk image from GitHub. This beta requires an Apple silicon Mac with macOS 26 or later.
  2. Open the disk image and drag Ocean to Applications. If you open it from the download instead, its installer can copy it there for you.
  3. Open Ocean from Applications and choose Use Ocean. Ocean handles wallpaper and screen-saver setup automatically.
  4. Find the wave icon in your menu bar. Choose Ocean Settings, or open Ocean again to see your controls.

Make it yours

Daylight: Follow Local Time, or hold the lighting at sunrise, sunset or another favorite time. Waves keep moving. Custom Time lets you choose an hour and minute.

Weather: Follow Local Weather, or choose a weather preview. Choose Follow Local Weather again to return to your area’s conditions.

Performance: Balanced is the starting point. Save Energy reduces detail and frame rate. Sharper adds detail. Ocean also adapts to battery, heat and covered windows.

Start at login: Turn this on if you want Ocean ready whenever you sign in. macOS may ask you to allow it in Login Items.

Pause: Stops the animation, including the native lock-screen wallpaper. A new display or wake transition may need one still frame to repaint.

Turn off or remove Ocean

In Ocean Settings, choose Turn Off Ocean. Ocean restores the wallpaper and screen saver it replaced, turns off Open at Login, and quits. It preserves wallpaper choices you made yourself afterward. Once it has quit, you can move Ocean from Applications to the Trash. Your appearance preferences remain saved.

Closing the settings window keeps Ocean running in the menu bar. To stop it, use Turn Off Ocean.

Updates and troubleshooting

Updates on GitHub opens the official release page. For a new version, turn off Ocean, download the new disk image, replace the app in Applications, then open it. If you open the new download directly, Install & Open can update the installed copy.

If setup needs attention, choose Repair Setup. If the ocean stops after an OS update, reopen Ocean and try Repair Setup. Native live wallpaper integration uses a macOS compatibility layer and can require an update when Apple changes it.

Copy Support Info copies the app version, macOS version and basic app settings. Paste it into a GitHub issue with a description of the problem. It does not include your IP address or saved coordinates. Nothing is sent automatically.

Privacy

After you choose Use Ocean, the app requests your general area from ipwho.is, using your internet connection’s public IP address. It keeps rounded latitude/longitude and the time zone locally. It does not request GPS access or save your raw IP address.

Approximate coordinates are sent to Open-Meteo for weather. Providers receive the normal connection information associated with these requests, including your public IP. Location is normally refreshed once per day and weather every 15 minutes; cached data provides an offline fallback. A VPN may change the apparent area.

Rendering and preferences stay on your Mac. Ocean includes no analytics, ads, account system or automatic support uploads. Clicking GitHub links opens GitHub in your browser. These independent services have their own privacy policies.
